# 制作前问题清单与背景选择

这是用户明确要求的制作流程。用于新建演示；对已有演示的小幅修改，只补问确实缺少的信息。当前任务若只是更新本技能，不要求用户为不存在的新演示填写问题。

## 第一轮：一次收集基本信息

先展示下列清单；把上下文已给出的答案直接填好，标明尚缺项目。可通过可用的提问工具发送一个可自由填写的简明表单，保留中文提问；不把多个字段拆成连续多轮追问。

1. **题目**：封面主标题是什么？是否有副标题？需保留哪种语言和大小写？
2. **作者信息**：显示哪些姓名、署名顺序、机构/课程、学号/职位、日期？允许明确不显示其中任一项。不要从参考稿、用户名或文件名猜测。
3. **主题与用途**：讲什么、面向谁、希望观众记住什么？
4. **篇幅与语言**：页数或演讲时长；中文、英文或双语。用户未指定画幅时填入16:9默认值。
5. **材料**：使用哪些论文、PDF、数据、提纲和必讲结论？材料不足时指出实际缺口。
6. **绘画偏好**：有无指定作品、画家、时期、色调、情绪或需要避开的意象？没有额外偏好时按主题隐喻/联想筛选。

将“第一条静态，后续逐次点击出现”作为已知要求直接列出，不重复向用户请求批准。只有用户提出变化时才调整。

主题已知时可在等待其他答案期间检索候选画作、阅读论文和准备提纲。标题/作者显示内容尚未确定，或背景尚未选定时，不开始正式幻灯片排版；未回答不等于同意默认选择。

## 第二轮：至少5幅画的可比较候选

以不同作品为计数单位，至少提供5幅，通常可准备6–8幅方便比较。优先依据博物馆作品元数据确认其媒介为油画或坦培拉。其他绘画媒介可另列备选，但不计入要求的5幅。

每幅用A、B、C等稳定编号，展示：

| 字段 | 要求 |
|---|---|
| 预览 | 能显示则嵌入预览；也可提供本地候选总览。无法显示时提供作品页，清楚说明预览不可用。 |
| 身份 | 作品题名、作者、年代、收藏机构、经来源确认的媒介。未知信息写未知。 |
| 主题关系 | 一句具体的隐喻/联想理由，说明与本次汇报的内容有什么关系。 |
| 构图 | 是否适合16:9裁剪、主体位置、适合放文字的区域；不能只按关键词排名。 |
| 清晰度 | 原图实际宽×高、检验来源；默认全高清目标为1920×1080像素。仅有长边或放大后的像素不足以证明高清。 |
| 链接 | 官方作品页、可得的原图/高清下载链接；链接不能伪造为搜索页或缩略图。 |
| 获取状态 | 已验证下载 / 元数据标注高清但未下载 / 需手动下载 / 分辨率不足 / 尺寸未核实。 |
| 来源使用信息 | 记录来源提供的公共领域或开放授权说明；不得把公开可访问等同于已确认授权。 |

对16:9全屏背景，原图裁剪后应仍能覆盖1920×1080；4K需求则按3840×2160检查。PPI标签与插值放大不能代替实际像素。头像式竖画并非自动排除，但要确认裁剪后的像素和主体完整性。

获取素材时始终选网站的 **Full resolution / Original file**。上面的1920×1080或3840×2160只是判断可用性的目标，不能因此放弃更高分辨率原始文件。保存原始下载文件；候选页所需的小预览另存，不替换原图。若网站标明原始像素尺寸，应与下载后解码尺寸核对；不一致时记录差异并重新核实链接。

脚本返回的是检索池，必须人工核对媒介、图像内容、主题关系和构图后才形成最终候选清单。不要将无关作品凑足5幅，也不要把同一画的不同尺寸/裁剪当不同作品。

## 下载失败与用户选择

先尝试公开API或作品页的完整分辨率原图链接；图像服务只在已确认其提供完整分辨率时用作正式下载。遵守公开服务的限速与获取方式；出现权限、登录、验证码或持续请求失败时停止自动重试，保留实际原因和可用链接。

下载失败不等于作品不能成为供用户选择的候选，但要标明可核实到什么程度。提供能到达作品的页面及已获得的高清图片URL，让用户自行下载；没有拿到原图URL就如实仅给作品页。不能将下载失败/尺寸未知标成“已验证高清”。不足5幅合格候选时继续换来源或向用户清楚说明尚缺的数量。

请用户按编号选择封面、章节及结尾的背景，可以选多幅或只选一幅复用。只有用户明确授权“替我选”时才代选。把选择写入本次任务的素材清单，包括作品编号、用途、来源与本地文件路径。

若用户自行下载，在正常聊天中说明需要提供文件或可访问的本地路径；不要用仅支持文本的提问工具要求上传附件。收到图片后再次核对真实像素和作品匹配，再继续排版。
