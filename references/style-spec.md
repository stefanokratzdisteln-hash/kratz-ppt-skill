# 风格规格与版式选择

## 三类依据

1. **用户明确偏好**：主题相关、具有隐喻/联想的油画或坦培拉背景；半透明黑色矩形蒙版；英文段落悬挂缩进；可视化优先论文截图。开始新稿前先收集标题作者等信息，提供至少5幅高清油画/坦培拉让用户选择；同页第一条内容静态显示，其余逐条用“出现”入场动画。
2. **样本实测**：2026-10-22检查用户指定的13页PPTX，16:9，Elephant / Times New Roman / Cambria Math；字号和颜色见配置文件。数值代表这一份样本，不构成对全部个人作品的统计。
3. **生成建议**：安全边距、每页强调色上限、截图分辨率、中文字体、内容密度等为可调整建议。用户的新内容、受众和场地可以改变它们。

## 版式家族

以下坐标为新稿建议，使用画幅比例 `[x,y,w,h]`，不是逐像素复制样本。背景均铺满。文字必须经过实际渲染检查。

| 版式 | 建议构图 | 用途 |
|---|---|---|
| 海报式封面 | 标题 `[.045,.25,.85,.45]`；黑色横带覆盖中部；署名右下 | 主题引入与结束呼应 |
| 概念讲解 | 标题 `[.05,.06,.90,.15]`；正文 `[.05,.27,.47,.63]`；图 `[.55,.28,.40,.60]`；画作全幅有效75%遮暗 | 定义、流程、方法 |
| 单图证据 | 标题 `[.05,.06,.90,.15]`；论文图 `[.05,.27,.55,.60]`；解释 `[.64,.27,.31,.60]` | 论文关键图与一句解读 |
| 大图优先 | 标题 `[.05,.05,.90,.12]`；论文图 `[.05,.22,.90,.62]`；简短结论 `[.05,.87,.90,.08]` | 密集曲线、消融、多面板证据 |
| 反思总结 | 标题 `[.05,.15,.90,.15]`；正文 `[.08,.43,.82,.43]`，正文蒙版再加深 | 局限、未来工作、结论 |

不要把所有页面强行排成同一左右分栏。根据图本身的长宽与可读性改变证据页方向。来源文字为新稿建议16–18 pt；空间不足可移至备注并在图旁保留短引文。

## 样本的关键关系

- 封面100 pt / 正文28 pt ≈ 3.57；常规标题40 pt / 正文28 pt ≈ 1.43；案例标题35 pt / 正文24 pt ≈ 1.46。
- 字体的厚重感来自Elephant字形，不应机械给所有标题再叠加粗体。
- 单层黑色蒙版50%；叠加的有效不透明度为 `1 - ∏(1 - opacity_i)`，双层50%等于75%。它是通道混合参数，不是人眼感知对比度降低百分比。
- 全幅背景仍有纹理和情绪；主要信息依靠文字、截图与局部暗区形成层级。
- 样本的手绘流程与公式是现有混合语言；新任务以用户明确偏好的原论文截图优先。

## 后续明确要求

问题清单、至少5幅高清候选、用户选图及逐条Appear动画来自2026-10-22后续指示，不是对参考稿动画或原有制作流程的测量结论。见 [制作前清单](preflight-and-background-choice.md)、[图片检索与下载](art-sourcing.md) 和 [动画实现](appear-animation.md)。

同日用户进一步明确：下载选择网站的Full resolution / Original file，保留完整分辨率原图；网站预览仅用于候选展示，不替代背景素材。无法自动下载原图时提供其链接供用户手动下载。

## 内容与证据的适配建议

- 普通讲解页尽量用2–4个短论点。图为核心时减少正文，必要时让图独占一页。
- 背景每个章节使用一幅起步，以叙事变化而非机械页数决定换图。整稿通常3–5幅起步，数量为建议。
- 论文截图以实际显示宽度计算分辨率，优先约200–300 ppi的PDF渲染；原图低清时不能靠插值宣称细节恢复。
- 检查白字和每种强调色在合成背景上的局部识别度。若需要自动指标，可补充对比度计算，但不得把未测结果标成合规。
- 图表原始底色允许为白色。优先保证科研信息完整，不能为统一暗色风格修改原图颜色。

## 文件与溯源

参考PPT只读保存在 `assets/reference.pptx`。它是视觉证据而非通用内容模板。源哈希和逐页度量在 `references/sample-metrics.json`，完整版说明在 `references/quantitative-report.md`。这些文件中的教学内容不应自动复制到新稿。

审计脚本面向本样本验证过的普通DrawingML/OMML。新文件出现旋转、组合图形、渐变、表格、图表或非标准继承时，应结合PowerPoint渲染检查并标明未覆盖项。
